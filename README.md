# ♠️ Poker Addaa Pro v10 (Web Push Notifications Edition)

### 🔔 Brand New Feature: Web Push Notifications for Banker & Players
- **Instant Banker Alert:** Whenever a seated player taps `Half (0.5x)`, `Full (1.0x)`, or `Double (2.0x)` rebuy, the server fires a background Web Push Notification with sound and vibration directly to the Banker's and Admin's phones — even if their screen is locked or browser is in the background!
- **Player Approval Alert:** Once the Banker taps `✓ Approve` or `✕ Reject`, the requesting player gets an instant notification: *"✅ Rebuy Manzoor! Banker ne aapka ₹500 ka rebuy approve kar diya."*
- **One-Tap Permission:** Bell icon (`🔔`) added in the header for quick 1-tap notification activation.
- **Works on iOS (PWA standalone mode) & Android (Chrome / Edge / Firefox).**
